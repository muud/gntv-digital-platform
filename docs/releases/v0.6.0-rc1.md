## Deployment notes

- Apply Alembic migrations in order through `202607291700`.
- Provide a high-entropy `INGEST_GATEWAY_TOKEN` in staging and production.
- Configure database, Redis, object storage, CDN signing, KMS, and optional `ELEVENLABS_API_KEY` values through the deployment environment.
- Keep media workers separate from API containers.
- CPU processing is the default. Enable GPU workers only with an approved worker image and explicit configuration.
- Generated media workspaces and outputs must use deployment-owned persistent or ephemeral volumes as appropriate.

## Known non-blocking items

- External providers and production infrastructure require deployment-specific credentials and connectivity.
